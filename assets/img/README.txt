Image assets used by the portfolio:

- hero-portrait.png  → circular hero portrait. If it is missing, the site
                       automatically shows initials instead (see
                       .initials-fallback in assets/css/style.css).

- about-portrait.png → portrait displayed in the About section.

- projects/          → 16:9 project thumbnails. Each project image is
                       referenced from the matching language JSON item.

- og-cover.jpg  → optional. 1200x630px image used as the preview image
                  when your site is shared on LinkedIn/Twitter/etc.
                  Referenced by the <meta property="og:image"> tag in
                  index.html. Skip it if you don't need link previews.

Keep images compressed (JPEG ~80% quality or WebP) so the site stays fast.
