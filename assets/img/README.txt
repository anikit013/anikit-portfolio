Drop your images here:

- profile.jpg   → your hero/about photo. Square, at least 500x500px.
                  If this file is missing, the site automatically shows
                  your initials instead (see .initials-fallback in
                  assets/css/style.css and the onerror handler on the
                  <img> tag in index.html), so the site still works
                  with zero images.

- og-cover.jpg  → optional. 1200x630px image used as the preview image
                  when your site is shared on LinkedIn/Twitter/etc.
                  Referenced by the <meta property="og:image"> tag in
                  index.html. Skip it if you don't need link previews.

Keep images compressed (JPEG ~80% quality or WebP) so the site stays fast.
